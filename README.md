# 智能反代系统 v1.2.3

基于 Cloudflare Workers 的边缘媒体库反代系统，专为加速访问家庭媒体服务器（Emby/Jellyfin/Plex）而设计。提供公开访问导航页、三网智能线路、优选域名测速与可视化后台管理。

## 功能特性

### 核心功能
- **智能路由反代** - 支持多种代理模式（保守 / 严格 / 兼容 / 强力）
- **节点健康检查** - 实时检测节点可用性与延迟
- **节点主动健康检查（定时巡检）** - 每 6 小时 cron 自动 ping 所有节点源站并写入健康状态，状态翻转时推送 Telegram 告警
- **DNS 智能调度** - 自动选择最优节点，每 6 小时更新一次
- **海报缓存加速** - 可选开启图片缓存，提升加载速度
- **直连代理** - 支持 `/https://任意URL` 直接透传任意源站（无需预先建节点）
- **Cloudflare 优选域名测速** - 边缘节点对 12 个社区优选域名并行测速，按客户端网段缓存最快域名，可作反代目标前缀
- **运行时故障转移** - 节点请求失败（5xx / 连接错误 / 超时）自动重试同路由备用节点，近期不可用节点 60 秒内直接跳过，秒级切换

### 访问与导航
- **公开访问导航页** - 主域 + 电信 / 联通 / 移动三网子域统一展示访问地址
- **支持的服务列表** - 后台已反代媒体库自动汇总展示（名称 / 图标 / 前缀）
- **源站线路健康检测** - 绿点（可访问）/ 红点（不可访问），悬停查看状态码
- **三网智能线路选择** - 按客户端运营商自动跳转最优子域，也可手动选择
- **PWA 离线支持** - 导航页可「添加到主屏幕」，Service Worker 缓存地址页离线也能看

### 安全防护
- **管理后台密码保护** - 后台 `/admin` 需 `ADMIN_TOKEN` 鉴权，未登录自动跳转登录页
- **PikPak 域名自动重定向** - 自动识别并跳转到 PikPak 官方域名，规避防盗链拦截
- **恶意请求拦截** - IP 黑名单、频率限制与请求过滤，仅记录真实播放请求，避免统计虚高

### 数据监控
- **数据大屏** - 实时流量统计、播放趋势、客户端分布、故障转移计数
- **访问者地理分布地图** - 世界地图热力显示近 7 天播放来源国家分布
- **节点延迟趋势** - 近 7 天各节点平均延迟曲线（测速自动记录历史）
- **节点热度榜** - TOP 5 今日播放排行
- **访客日志** - 记录访问来源和播放行为
- **Telegram 播报** - 自动推送节点状态和统计简报

### 数据与存储
- **D1 数据库** - 数据持久化存储，自动建表，无需手动初始化

### 管理功能
- **可视化控制台** - 完整的 Web 管理界面（后台位于 `/admin`）
- **现代化 UI** - 深蓝渐变风格管理后台，卡片式路由管理
- **节点拖拽排序** - 支持自定义节点优先级
- **批量操作** - 全选、批量修改模式、批量删除
- **在线更新** - 一键从 GitHub（[PzErebus/fandai](https://github.com/PzErebus/fandai)）拉取最新代码
- **系统设置折叠分组** - 高级模块统一收纳于底部「系统设置」

## 技术栈

- **Cloudflare Workers** - 边缘计算平台
- **Cloudflare D1** - 边缘 SQLite 数据库
- **Cloudflare GraphQL Analytics** - 流量统计分析
- **SortableJS** - 拖拽排序
- **Chart.js** - 数据可视化

## 部署说明

### 前置要求
1. Cloudflare 账号
2. Wrangler CLI 工具
3. 一个已绑定到 Cloudflare 的域名

### 环境变量配置

复制 `wrangler.toml.example` 为 `wrangler.toml`，并在其中配置以下变量（`wrangler.toml` 含密钥，已被 `.gitignore` 排除，不会提交到仓库）：

```toml
name = "fandai-worker"
main = "worker.js"
compatibility_date = "2026-05-23"
compatibility_flags = ["nodejs_compat"]

[[d1_databases]]
binding = "DB"
database_id = "your-d1-database-id"

[[triggers]]
crons = ["0 */6 * * *"]  # 每6小时执行DNS智能调度

[vars]
ADMIN_TOKEN = "your-admin-password"
CF_ACCOUNT_ID = "your-cf-account-id"
CF_API_TOKEN = "your-cf-api-token"
CF_DOMAIN = "your-domain.com"
CF_WORKER_NAME = "fandai-worker"
CF_ZONE_ID = "your-cf-zone-id"
TG_BOT_TOKEN = "your-telegram-bot-token"
TG_CHAT_ID = "your-telegram-chat-id"
```

### 部署命令

```bash
wrangler deploy
```

## 使用说明

1. 访问部署后的 Worker 地址（主域或三网子域），打开公开访问导航页
2. 访问 `/admin` 使用 `ADMIN_TOKEN` 登录管理后台
3. 添加媒体库节点（支持多目标地址）
4. 开启需要的功能（缓存、健康检查、智能 DNS 等）
5. 复制直达链接到播放器使用；需要临时代理任意源站可直接用 `/https://目标地址`

## 注意事项

- 请妥善保管 `ADMIN_TOKEN`，不要泄露
- `CF_API_TOKEN` 需要 Zone:Read 和 Analytics:Read 权限
- D1 数据库需要提前创建并绑定
- `wrangler.toml` 含密钥，已被 `.gitignore` 排除，请勿手动提交
